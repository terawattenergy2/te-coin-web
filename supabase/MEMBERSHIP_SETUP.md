# ตั้งค่าสูตร Membership รุ่น A / B / C / D

หน้าเว็บใช้สูตรใหม่ได้หลังรัน `006_membership_model.sql` ทั้งไฟล์ใน Supabase SQL Editor ของโปรเจกต์ TeraCoin แล้วรีเฟรชแอป (ต้องติดตั้ง 001, 002 และ 004 แล้ว; 005 ไม่จำเป็น)

ไฟล์นี้เก็บค่าตั้งระบบเดิมไว้ใน `tc_settings.membership_previous_settings` ก่อนเปลี่ยนสูตรหลักครั้งแรก รันซ้ำได้โดยไม่รีเซ็ตค่าที่ Admin แก้แล้ว ไม่เปลี่ยนยอดสะสม/ยอดใช้หรือ snapshot ในประวัติเดิม แต่ประเมิน Liability คงเหลือใหม่ตามสูตรปัจจุบัน

## ค่าที่เปลี่ยนได้ในหน้าเว็บ

- **ตั้งค่าระบบ:** ตัวคูณ B เริ่มต้นและแยกตามกลุ่มสินค้าที่โหลดจาก Supabase, คอมมิชชันเริ่มต้น/ตามกลุ่ม, ช่องราคาต้นทุนฐาน, อัตราสำรอง Liability, โอกาส Lucky Draw เริ่มต้น
- **บันทึกยอดขาย:** ราคาขายจริงก่อน VAT ต่อหน่วย, จำนวน, คอมมิชชันเฉพาะรายการ (เว้นว่างใช้ค่าของกลุ่มหรือค่าเริ่มต้น) บันทึกหลายกลุ่มสินค้าในบิลเดียวได้
- **แลกรางวัล → จัดการรางวัล → แก้ไข:** มูลค่าสิทธิประโยชน์/ค่าตั๋ว, D ของรางวัลนั้น, จำนวนสิทธิ์, และโอกาส Lucky Draw เฉพาะรางวัล
- **ตั้งค่าระบบ → สูตร:** ยังเลือกช่องข้อมูลภาษาไทยและบวก ลบ คูณ หารได้ สูตรที่แก้มีผลแทนสูตรตั้งต้น ต้องตรวจผลตัวอย่างก่อนบันทึก

## สูตรตั้งต้น

คอมมิชชันต่อหน่วย = ราคาขายจริงก่อน VAT × อัตราคอมมิชชัน

A ของรายการ = (ราคาขายจริงก่อน VAT − ต้นทุนฐาน − คอมมิชชันต่อหน่วย) × จำนวน

C = ปัด 2 ตำแหน่ง(max(0, A × B ของกลุ่มสินค้า)) จากนั้นรวม C ทีละรายการเป็น TC ทั้งบิล

TC แลกรางวัล = มูลค่ารางวัล ÷ D ปัดขึ้นถึง 0.01 TC

สิทธิประโยชน์เป็นบาท = TC × D (D มากขึ้น ใช้ TC น้อยลงเมื่อมูลค่ารางวัลเท่าเดิม)

Liability = แต้มคงเหลือ × อัตราสำรอง ตั้งต้น 0.60 บาท / TC เป็นสมมติฐานที่ปรับได้ แยกจาก D และไม่ได้หมายถึงต้นทุนรางวัลที่จ่ายจริง

B ตั้งต้นตามเคส: Battery 0.5, SigenStor Inverter 0.7, Neo Inverter 0.2, Neo Battery 0.2; กลุ่มอื่นใช้ค่าเริ่มต้น 0.5 คอมมิชชันเริ่มต้น 1.5% ของยอดขายจริง (บิลที่ใช้ 1.2% ให้ระบุ 0.012)

D ตั้งต้น: Bundle 1.05, Cashback 0.50, Lucky Draw 0.75, Tour 1.15; รางวัลแต่ละชิ้นแก้ D ได้อิสระ โอกาสสุ่มเริ่มต้น 80% ไม่มีการรับประกันว่าจะชนะครบสัดส่วนในจำนวนครั้งจำกัด

## ตัวอย่างที่ตรวจแล้ว

Battery: ขาย 82,700 บาท × 4, ฐาน Tier 2 72,600 บาท, คอมมิชชัน 1.5%, B=0.5

ยอดขาย 330,800 − ฐาน 290,400 − คอมมิชชัน 4,962 = A 35,438 บาท

C = 35,438 × 0.5 = **17,719 TC**

สามบิลตามเคสรวม **83,489.20 TC**; แลกมูลค่า 15,750 บาทที่ D=1.05 ใช้ 15,000 TC และทัวร์ 55,000 บาทที่ D=1.15 ใช้ 47,826.09 TC จะเหลือ **20,663.11 TC** สำรองที่ 0.6 = **12,397.87 บาท**

การแลกในเว็บเป็นหนึ่งหน่วยรางวัล/ครั้ง หากต้องการสินค้าหลายหน่วย ให้ตั้งชุดรางวัลและมูลค่ารวมเอง ยังไม่มีการแบ่ง TC ตามงบซื้อสินค้าและเก็บส่วนต่างเครดิตโดยอัตโนมัติ
