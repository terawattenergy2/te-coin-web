ใบเสร็จรับเงินที่ชำระครบ · FlowAccount Production

วิธีจัดหมวดและคำนวณยอด — กรุณาอ่านก่อนใช้ยอด

ระบุ Sigenergy จากชื่อสินค้าที่มี Sigenergy หรือ Sigen เท่านั้น รายการชื่อกว้าง เช่น Dummy Battery หรือ Fast Charging License จะไม่ถือเป็น Sigenergy โดยอัตโนมัติ หมวดอื่นจัดจากชื่อ/ตระกูลรุ่นเพื่อช่วยค้นหา ยังไม่ใช่หมวดในระบบบัญชี

รวมชื่อซ้ำเฉพาะตัวพิมพ์และช่องว่างที่ต่างกัน ไม่รวมรุ่นหรือขนาดที่คล้ายกันอัตโนมัติ ชื่อเซลส์ใช้ตามเอกสาร ชื่อไทย/อังกฤษของคนเดียวกันอาจยังแยกคน ต้องยืนยันก่อนรวม

ยอดก่อน VAT ของแต่ละรายการ = ยอดสุทธิไม่รวม VAT ของบิล × สัดส่วน item.total ต่อผลรวมรายการทั้งบิล โดยปันเศษสตางค์ให้ตรงฐานก่อน VAT ของบิล วิธีนี้รวมผลของส่วนลด/หักยอดท้ายบิลตามสัดส่วน เป็นวิธีทำรายงานตรวจสอบ ไม่ใช่การยืนยันว่ารายการส่วนลดนั้นเป็นของสินค้าตัวใดโดยเฉพาะ สำหรับใบเสร็จรวมที่ API ส่งยอดรวม VAT ไว้ในช่องก่อน VAT และไม่มีราคาแยกรายการ ระบบใช้ฐาน VAT ของใบเสร็จตามรายงาน FlowAccount

ใบเสร็จรับเงินแต่ละฉบับนับหนึ่งครั้ง สินค้าชื่อซ้ำต่างใบยังเป็นยอดขายคนละรายการ ชุดรายงานนี้ไม่ได้นำใบลดหนี้มาหัก จึงไม่ใช่ยอดขายสุทธิหลังคืนสินค้า และไม่ใช่ยอดรับเงินจริง เงินมัดจำที่ยืนยันใบเสนอราคาได้จะแบ่งตามมูลค่าของสินค้าในใบเสนอราคา โดยใช้ยอดจากใบเสร็จและไม่เพิ่มจำนวนหน่วยสินค้า ค่าขนส่งที่ระบุรุ่นได้จากใบเสร็จหรือเอกสารอ้างอิงจะแสดงยอดย่อยใต้รุ่นนั้น

API เส้นนี้แสดงเฉพาะสินค้าที่ปรากฏในใบเสร็จรับเงินที่ดึงมา ไม่ใช่สินค้าทุกตัวในคลัง และยอดรายคนขึ้นกับการระบุ salesName ในเอกสาร
